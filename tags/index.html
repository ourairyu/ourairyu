这几天往飞书里导在其他内容平台的数据，大概流程是：

  1. 手动从 HTTP 请求中抓取列表数据；
  2. 保存到本地作为 raw 的 JSON 文件中；
  3. 用 Trae 按要求自动清洗数据存到另一个 JSON 文件中；
  4. 让数字员工用 skill 把清洗后的数据导入「内容分发」表。

前三步都是人类主导，因为还是人更具性价比。

今天在 chat flow 中下达指令时，数字员工犯了几个「大」错，气得我破口大骂，是真气到了！
