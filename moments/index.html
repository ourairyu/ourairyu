会用到多台电脑开发同一个项目，有什么方法可以减少 Git 仓库克隆数吗？

这几天我断断续续地优化了下自己的 Git 仓库管理方案，包括本地仓库和托管服务两部分——

将 2T 的 Mac mini 作为本地仓库存储中心，MacBook 和开发专用机在内网通过文件共享 + 软链接的方式把 Mac mini 上文件当本地文件操作。

这样可大幅降低重复冗余仓库带来的宝贵硬盘空间浪费，MacBook 和开发专用机仅作为数据读写客户端和算力节点，能无限拓展——这就是存算分离思想的小小应用。

Mac mini 上的 Git 仓库只直接与内网自部署的 Gitea 进行关联且作为主备份，再由 Gitea 的仓库镜像能力把文件推送到 GitLab 和 GitHub 云服务做全量次级备份。
