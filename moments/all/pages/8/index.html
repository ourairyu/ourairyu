因而，Sophye 这个项目诞生了！

  1. QiiDB 的 Qii 来自「炁」；
  2. KnoSys 是 gnosis 的变体，意为「知识」；
  3. Sophye 是 Sophia 或 Sophie 的变体，意为「智慧」；
  4. LinXoid 则是 link 的变体加上代表机器人的 -oid 后缀，字母 x 有联结的意象。人工智能
