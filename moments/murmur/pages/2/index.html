弄以数字员工团队为核心的 AIOPC 要做的事一点不比传统公司少：搭团队，建流程，跑业务。

昨天让我的数字分身「欧雷」也加入了「人生集团公司」，负责几个具体的业务线。

至此，数字员工团队已有 6 人，相互间信息怎么流转，怎么协作成了首要解决问题。

昨天尝试用飞书云文档协作踩坑了——

机器人更新文档时基本都是整个文档覆盖式更新，而非在具体的文档块里更新，这就使历史版本 diff 失效了。

现在采取独立的 Markdown 文档 Git 仓库去协作，比用飞书云文档方便、实惠很多。

要想让这个数字员工团队真正自主运转起来，还需要花些时间打磨。

我的「人生集团公司」这家「一人公司（OPC）」的数字员工团队核心成员终于配齐！🤟🏼🤟🏼🤟🏼接下来就是搭建相互之间的协作流程，然后推进项目一步步落地！💪🏼💪🏼💪🏼这两天被他们催着要计划，要资料，要数据，有种奇妙的感觉……😂😂😂还有就是，免费额度有些不够用了……[图片]查看详情
