当初买迷你主机时装的 Windows 10 和黑苹果双系统，分别装在 512G SSD 中。

由于黑苹果几乎不用，装它的 SSD 就闲置出来了，本打算装个硬盘盒给 Mac mini 做外挂扩展。

但结合当前那些装满文件的 HDD 都是 NTFS 格式，还是把这 SSD 格式化继续用在迷你主机里当热数据存储吧。

与此同时，把俩电脑的定位稍微调整下——

Mac mini 依然运行 Jellyfin 服务端作为影音中心，但媒体库是挂载的 Windows 共享文件夹，而非 macOS 本地文件。

在 Windows 上用 qBittorrent 下载资源，再用 tinyMediaManager 刮削元数据。

近期在看的片子放在格式化后的 SSD 上，看过的都挪到硬盘柜中的 HDD 归档，它们都可被 Mac mini 挂载。

之后再搭建（复古）游戏中心时也沿用上述「分工」。

总之就是，资源存储主要集中在迷你主机和硬盘柜上，Mac mini 则是其他终端访问家庭服务的统一入口。

像 VS Code 远程开发、Git 私有部署等软件开发相关服务都部署在 Mac mini 上。
